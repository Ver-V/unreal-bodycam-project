# Bodycam

Unrecord 스타일 바디캠 1인칭 슈터 프로토타입 (Unreal Engine 5.5, C++)
싱글 플레이 좀비 익스트랙션 게임을 목표로 개발 중입니다.

> **에셋은 포함되어 있지 않습니다.** Fab 및 Epic 템플릿 에셋은 라이선스상 재배포할 수 없어 `Content/`를 제외했습니다.
> 이 저장소는 C++ 소스와 설정, 도구 스크립트만 담고 있습니다.

## 주요 구현

### 가슴 장착 바디캠 리그 — `BodycamRigComponent`
- 카메라를 조준(ControlRotation)과 분리하고, 감쇠 스프링으로 늦게 따라가게 하여 몸통에 달린 카메라의 무게감 표현
- 스프링은 1/120초 고정 서브스텝으로 적분해 프레임레이트와 무관하게 동일한 느낌 유지
- 최대 지연 각도(Leash)에서 속도까지 맞춰 끊김 없는 추종
- 이동 거리 기반 발걸음 흔들림, Perlin 노이즈 호흡, 반동/착지 킥 스프링
- 팔은 카메라(몸통)에 붙어 같은 흔들림을 공유하고, 조준 방향으로 일부만 회전(`ArmAimFollow`) → 총이 화면 안에서 움직이는 바디캠 특유의 구도
- 정조준 시 추종/흔들림/화각을 부드럽게 블렌드

### 권총 — `BodycamPistolComponent`
- 반자동 히트스캔: 총구 소켓에서 **총이 실제로 가리키는 방향**으로 트레이스 (화면 중앙이 아님)
- 탄창 + 약실 탄약 모델 (17+1), 일반/빈 탄창 장전 분기, 몽타주 종료 델리게이트로 장전 완료 처리
- 조준 반동(명중에 영향)과 카메라 반동(연출)을 분리
- 탄착 이펙트(Niagara), 탄흔 데칼, 리버브 센드가 걸린 2D 총성
- 절차적(procedural) 정조준

### 상호작용 — `IBodycamInteractable`
- `BlueprintNativeEvent` 인터페이스로 C++/블루프린트 양쪽에서 구현 가능
- 조준 방향 스피어 스윕으로 대상 탐색 (조준점 없는 바디캠에 맞춘 판정)

### 에셋 임포트 문제 해결 — `Tools/fix_glock.py`
Fab의 G17 FPS 애니메이션 팩을 임포트하면 **총이 통째로 사라지는** 문제를 분석해 해결했습니다.
- 원인: 총 부품이 스킨 메시가 아닌 노드에 붙은 리지드 메시라, 스켈레탈 메시 임포트 시 제외됨
- 해결: glTF를 직접 파싱해 총 부품 노드를 조인트로 승격하고 100% 가중치로 스키닝, 스킨을 하나로 병합, 총구 조인트 추가, 애니메이션 시작 시간 정규화
- 원본 대비 정점 위치 오차 1e-7m로 검증

## 빌드

2. `Bodycam.sln`을 열고 **Development Editor / Win64**로 빌드
