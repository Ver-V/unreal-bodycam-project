# Bodycam

Unrecord 스타일 바디캠 1인칭 좀비 탈출 게임 (Unreal Engine 5.5, C++)

어두운 폐건물에서 총과 손전등만으로 열쇠를 찾아 탈출하는 싱글 플레이 데모입니다.
가슴에 단 바디캠 시점, 소리와 시야로 플레이어를 찾는 좀비, 목표에 따라 바뀌는 게임 흐름을 C++로 구현했습니다.

- **플레이 영상**: (링크 추가 예정)
- **다운로드 (Windows)**: (링크 추가 예정) · 권장: RTX 20 시리즈 이상

> **에셋은 포함되어 있지 않습니다.** Fab 및 Epic 템플릿 에셋은 라이선스상 재배포할 수 없어 `Content/`를 제외했습니다.
> 이 저장소는 C++ 소스와 설정, 도구 스크립트만 담고 있습니다.

## 게임 흐름

총 줍기 → 열쇠 찾기 → 잠긴 출구 열기 → 탈출 구역 진입.
열쇠 없이 출구에 먼저 가면 목표가 "열쇠를 찾아라"로 바뀝니다. 열쇠를 줍는 순간 지나온 복도에 좀비가 시간차로 등장합니다.

## 주요 구현

### 가슴 장착 바디캠 리그 — `BodycamRigComponent`
- 카메라를 조준(ControlRotation)과 분리하고, 감쇠 스프링으로 늦게 따라가게 하여 몸통에 달린 카메라의 무게감 표현
- 스프링은 1/120초 고정 서브스텝으로 적분해 프레임레이트와 무관하게 동일한 느낌 유지
- 최대 지연 각도(Leash)에서 속도까지 맞춰 끊김 없는 추종
- 이동 거리 기반 발걸음 흔들림, Perlin 노이즈 호흡, 반동/착지/피격 킥 스프링
- 팔은 카메라(몸통)에 붙어 같은 흔들림을 공유하고, 조준 방향으로 일부만 회전(`ArmAimFollow`) → 총이 화면 안에서 움직이는 바디캠 특유의 구도
- 사망 시 카메라와 팔이 중력처럼 가속하며 바닥으로 떨어지고 옆으로 누운 뒤 페이드아웃

### 권총 — `BodycamPistolComponent`
- 반자동 히트스캔: 총구 소켓에서 **총이 실제로 가리키는 방향**으로 트레이스 (화면 중앙이 아님)
- 탄창 + 약실 탄약 모델 (17+1), 예비 탄약 제한, 일반/빈 탄창 장전 분기
- `ApplyPointDamage`로 맞은 뼈와 총알 방향 전달 → 헤드샷, 래그돌 방향
- 조준 반동(명중에 영향)과 카메라 반동(연출) 분리, 탄착 이펙트, 탄흔 데칼, 리버브 총성

### 손전등 — `BodycamCharacter`
- 총을 줍기 전에는 가슴, 주운 뒤에는 총구 아래에 장착
- 방향은 히트스캔과 같은 조준 기준이라 **빛이 비추는 곳 = 총알이 맞는 곳**
- 루멘 반사광이 방 전체를 밝히지 않도록 간접광 강도 조정

### 좀비 AI — `BodycamZombie`
비헤이비어 트리와 애님 블루프린트 없이 C++ Tick과 애니메이션 시퀀스 3개(대기·걷기·공격)로 구현했습니다.

| 기능 | 구현 |
| --- | --- |
| 시야 | 거리 → 내적으로 시야각 → 라인 트레이스로 가림 판정. 추적 전에는 0.2초 간격으로만 검사 |
| 근처 감지 | 방향 무관. 플레이어가 웅크리면 범위가 줄어 몰래 지나갈 수 있음 |
| 총소리 | 발사 시 범위 안 좀비에게 알림. 사이에 벽이 있으면 범위 축소 |
| 순찰 | 배치 위치 주변 내비 메시 위 무작위 지점으로 느리게 이동 |
| 추적 / 공격 | `AAIController::MoveToActor`, 사거리 안에서 공격 애니메이션 + 타이머 판정 |
| 피격 / 사망 | 총알이 메시 피직스 바디에 맞도록 채널 분리 → 뼈 이름으로 헤드샷 판정, 사망 시 맞은 뼈를 총알 방향으로 밀어 래그돌 |

- 걷기 애니메이션 재생 속도를 이동 속도에 맞춰 발 미끄러짐 방지
- 화면 밖 좀비는 포즈 계산 생략, 먼 좀비는 애니메이션 갱신 빈도 감소

### 게임 흐름 — 목표, 열쇠, 문, 스폰
- 목표 문구는 캐릭터가 관리하고 HUD는 문구와 투명도만 바인딩 (나타났다가 몇 초 뒤 사라짐)
- `BodycamKeyPickUp`, `BodycamAmmoPickUp`, `BodycamDoor`(E로 여닫기, 잠긴 출구 옵션), `BodycamExtractionZone`
- `BodycamZombieSpawnPoint`: 열쇠·총 획득 같은 이벤트에 맞춰 지연 시간을 두고 좀비 생성

### 상호작용 — `IBodycamInteractable`
- `BlueprintNativeEvent` 인터페이스로 C++/블루프린트 양쪽에서 구현 가능
- 조준점 없는 바디캠에 맞춘 **화면 중앙 기준 3단계 판정**: 메시 면 정밀 트레이스 → 스피어 스윕 → 시야각 안 가장 가까운 대상

### 사운드
- 좀비 소리의 거리 감쇠와 리버브 상한을 코드에서 생성
- 모든 좀비가 공유하는 동시 재생 제한 (가까운 것만 들림)
- 발소리는 애니메이션 노티파이가 아닌 **걸은 거리** 기준 → 화면 밖 좀비의 발소리도 들림
- 주인공 대사(들킴·피격·처치)와 체력에 따라 커지는 숨소리

### 에셋 임포트 문제 해결 — `Tools/fix_glock.py`
Fab의 G17 FPS 애니메이션 팩을 임포트하면 **총이 통째로 사라지는** 문제를 분석해 해결했습니다.
- 원인: 총 부품이 스킨 메시가 아닌 노드에 붙은 리지드 메시라, 스켈레탈 메시 임포트 시 제외됨
- 해결: glTF를 직접 파싱해 총 부품 노드를 조인트로 승격하고 100% 가중치로 스키닝, 스킨을 하나로 병합, 총구 조인트 추가, 애니메이션 시작 시간 정규화
- 원본 대비 정점 위치 오차 1e-7m로 검증

### 조명 정리 도구 — `Tools/light_cleanup.py`
에디터 Python 스크립트로 레벨의 모든 라이트(블루프린트 내부 포함)와 발광 판을 한 번에 끕니다.

## 성능

| 측정 | GPU |
| --- | --- |
| 기준 (Derelict Corridor, QHD, RTX 4080 Super) | 9.36 ms |
| 조명 정리 후 | **6.06 ms (−35%)** |

`ProfileGPU`로 조명(디퍼드 라이팅 + 그림자)이 가장 큰 비용임을 확인하고, 분위기 연출(어두운 건물 + 비상등)과 함께 줄였습니다.

## 디버깅 사례 (일부)

| 증상 | 원인 |
| --- | --- |
| 총을 쏘고 30초 뒤 벽이 사라짐 | 데칼 `SetFadeOut`의 `DestroyOwnerAfterFade` 기본값 true → 탄흔이 붙은 벽 액터를 파괴 |
| 좀비가 문을 못 지나감 (플레이어는 통과) | 트리거 박스가 몸은 안 막지만 내비 메시에 구멍을 냄 |
| 라이트를 다 꺼도 바라볼 때만 빛이 남 | 이미시브 머티리얼 + 루멘 화면 공간 추적 + 블룸 |
| 총구 섬광이 1초쯤 남음 | 루멘 간접광의 시간 누적 |
| 렌즈 효과를 넣자 화면이 확대됨 | 업스케일 이후 단계에서 렌더 해상도 기준 UV 변환 사용 |
